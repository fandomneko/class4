# Design System — 한국콜마 웹사이트 리뉴얼

> 이 문서는 `kolmar/index.html`, `kolmar/css/main.css`, 공통 초기화 파일 `css/default.css`를 기준으로 작성했습니다. 기존 메인 페이지의 시각 디자인과 구조를 변경하기 위한 문서가 아니라, 이후 서브 페이지를 제작할 때 현재 메인 페이지의 규칙을 일관되게 이어가기 위한 기준입니다.
>
> **작성 기준:** 저장소에서 확인한 실제 코드. CSS에 정의되지 않은 수치나 디자인 규칙은 임의로 추가하지 않았습니다. 반응형·상태 디자인처럼 코드에서 확인되지 않는 부분은 '미정/보완 필요'로 구분합니다.

---

## 1. Project Overview

### 사이트 목적
- 한국콜마의 기업 및 사업 정보를 소개하는 기업형 웹사이트 리뉴얼 프로젝트입니다.
- 메인 페이지는 R&D, 회사소개, ESG, 소식, IR 정보를 한 페이지의 섹션으로 구성합니다.
- 상단 GNB와 메가 메뉴를 통해 주요 정보 영역으로 이동하고, 각 콘텐츠의 '자세히 보기' 또는 목록 항목을 통해 세부 정보를 탐색하도록 구성되어 있습니다.

### 디자인 방향
- **기술력과 신뢰를 전달하는 기업형 디자인:** 블루·네이비 계열을 중심으로 연구개발과 전문성을 표현합니다.
- **콘텐츠별 분위기 구분:** R&D는 밝은 블루 그라데이션, 회사소개는 이미지 중심, ESG는 블루 톤의 가로형 콘텐츠, 소식은 어두운 배경과 카드, IR은 밝고 간결한 목록으로 구분합니다.
- **이미지와 텍스트의 역할 분리:** HERO와 회사소개 영역은 이미지의 인상을 강조하고, R&D·ESG·소식·IR은 설명 텍스트와 정보 탐색에 초점을 둡니다.

## 2. Brand Identity

### 브랜드 인상
코드에 사용된 블루·네이비 계열, 연구 이미지, 기술 관련 문구를 바탕으로 **전문성, 기술 신뢰, 연구개발, 미래지향성**을 전달하는 방향으로 해석할 수 있습니다.

### 시각적 특징
- 대표 색상은 선명한 블루 `#276EF1`과 딥 네이비 `#101C3A`입니다.
- 밝은 하늘색 계열은 R&D 영역의 배경에 사용됩니다.
- 어두운 네이비와 반투명 흰색 카드는 소식 영역의 정보 가독성과 깊이감을 만듭니다.
- Pretendard Variable을 기본 서체로 사용합니다.
- 이미지에는 넓은 화면을 채우는 방식(`object-fit: cover`)을 주로 적용합니다.

> 위 브랜드 인상은 프로젝트 코드에서 관찰되는 시각 요소를 바탕으로 한 디자인 해석이며, 기업의 공식 브랜드 가이드 문구를 옮긴 것은 아닙니다.

## 3. Design Principles

1. **메인 페이지와 시각적 연결 유지**  
   서브 페이지에서도 블루·네이비 팔레트, Pretendard Variable, 공통 헤더·푸터를 유지합니다.

2. **콘텐츠 성격에 맞는 정보 표현**  
   기업 소개는 이미지와 핵심 문구, 연구·ESG는 설명과 이미지, 소식은 카드형 요약, IR은 구분선이 있는 목록 구조를 우선합니다.

3. **정보 위계 명확화**  
   페이지 제목 → 섹션 제목 → 카드 제목 → 설명 순서로 읽히도록 구성합니다. 제목 크기와 굵기는 기존 페이지의 대응 요소를 기준으로 선택합니다.

4. **반복 UI 재사용**  
   동일한 목적의 버튼·카드·목록은 기존 컴포넌트의 형태와 상태 표현을 재사용합니다. 페이지마다 새로운 모양을 임의로 만들지 않습니다.

5. **가독성과 접근성 유지**  
   한글 줄바꿈은 공통 초기화의 `word-break: keep-all`을 기본으로 하고, 키보드 포커스 표시를 제거하지 않습니다.

6. **기존 메인 페이지 보존**  
   이 문서를 적용한다는 이유로 메인 페이지의 기존 디자인, 콘텐츠 순서, 이미지, 레이아웃을 변경하지 않습니다. 서브 페이지에 필요한 규칙만 확장합니다.

- HERO 이미지 오버레이: `rgba(5,12,30,.38)`에서 투명으로 이어지는 그라데이션
- 회사 카드 기본 오버레이: `linear-gradient(0deg, rgba(4,13,28,.72), rgba(4,13,28,.18))`
- 회사 카드 01·03·04 오버레이: `rgba(0, 0, 0, .6)`
- R&D 버튼·카드·탭: 흰색 또는 네이비 계열의 반투명 배경
- 소식 카드: 흰색 `0.12` 투명도 유리 배경, 네이비 `0.85` 투명도 배경, 강조 카드 블루 `rgba(42, 102, 204, 0.85)`

### 사용 규칙
- 기업의 주요 강조색은 기존 블루 계열을 우선합니다.
- 넓은 어두운 배경은 HERO와 소식처럼 이미지·콘텐츠를 강조하는 영역에서 사용합니다.
- 밝은 콘텐츠 영역은 흰색 또는 R&D·ESG에 이미 사용된 밝은 블루 계열을 기준으로 합니다.
- 위 변수 중 실제 메인 CSS에서 사용되지 않는 변수도 있으므로, 사용 목적이 확인되지 않은 변수에 새로운 역할을 임의로 부여하지 않습니다.
- 서브 페이지에 새 색상이 꼭 필요하다면 메인 페이지의 기존 색상과 대비를 확인한 뒤 추가 여부를 결정합니다.

## 5. Typography

### 기본 서체
- `--font: "Pretendard Variable", Pretendard, sans-serif`
- HTML에서 `../font/css/pretendardvariable.css`를 불러옵니다.
- 기본 본문은 `body`에서 `var(--font)`를 사용합니다.
- 영문·숫자·한글이 함께 있는 제목과 정보에도 동일한 서체 스택을 우선 적용합니다.

### 타이포그래피 적용 규칙
- 페이지 제목은 해당 서브 페이지의 가장 중요한 정보이므로 메인 페이지의 섹션 제목 크기 체계를 참고합니다.
- 카드 제목은 본문보다 굵고 크게 설정합니다.
- 설명 텍스트는 충분한 행간을 확보합니다. 기존 코드에서 설명 텍스트는 주로 1.5~1.7의 행간을 사용합니다.
- `clamp()`가 적용된 제목은 화면 폭에 따라 글자 크기가 유동적으로 변하므로, 고정 크기로 임의 변경하지 않습니다.
- `SECTION TYPOGRAPHY: minimum 16px` 구간에서 일부 작은 글자 선언을 16px로 다시 지정합니다. 따라서 실제 적용값은 앞쪽 선언만 보지 말고 CSS 뒤쪽의 재선언까지 확인해야 합니다.
- 헤더·푸터는 메인 CSS에서 상대적으로 작은 크기를 사용하므로 콘텐츠 본문과 동일한 최소 크기 규칙으로 간주하지 않습니다.

## 6. Layout & Spacing

### 공통 컨테이너
- `.section-inner`: `width: min(1540px, calc(100% - 60px))`, `margin: 0 auto`
- 콘텐츠는 최대 1540px까지 넓어지고, 화면 양쪽에는 최소 30px씩의 계산상 여백을 확보합니다.
- 메가 메뉴 내부도 `max-width: 1540px`를 사용합니다.
- 헤더는 컨테이너와 달리 `padding: 0 4.2%`로 화면 가장자리 기준 여백을 사용합니다.

### 주요 레이아웃
| 영역 | 레이아웃 방식 | 실제 간격·크기 |
|---|---|---|
| Header | Flex | 높이 76px, 좌우 padding 4.2% |
| GNB | Flex | `gap: clamp(22px, 4vw, 64px)` |
| 메가 메뉴 | Grid | 3열, 열 비율 1.1fr / 1fr / 1.15fr, gap 28px |
| HERO | 전체 너비 | 높이 `min(760px, 66vw)`, 최소 500px |
| R&D 내부 | Grid | 열 비율 .75fr / 2fr, gap 54px |
| R&D 카드 | Grid | 3열, gap 20px |
| 회사소개 | Grid | 4열, 카드 최소 높이 924px |
| ESG 항목 | Flex | 최소 높이 260px, padding 34px 60px |
| ESG 이미지 | 고정 비율 폭 | 너비 36%, 높이 190px, 왼쪽 margin 40px |
| 소식 내부 | Grid | 좌측 소개 240px + 콘텐츠, gap 36px |
| 소식 카드 열 | Grid | 2열, gap 18px |
| 소식 카드 묶음 | Flex column | gap 16px |
| IR 목록 | 세로 목록 | 위·아래 선, 항목 최소 높이 62px |
| Footer | Flex | gap 40px, 상하 padding 28px / 32px |

### 섹션별 여백
- R&D: 위아래 padding 76px
- ESG: 위 78px, 아래 90px
- 소식: 위 90px, 아래 100px
- IR: 위 80px, 아래 70px
- 회사소개 카드: 최소 높이 924px

### 적용 규칙
- 서브 페이지의 본문 폭은 `.section-inner`를 우선 재사용합니다.
- 콘텐츠가 여러 열로 나뉘면 기존 페이지처럼 Grid를 우선 고려하고, 같은 종류의 요소를 한 방향으로 나열하면 Flex를 사용합니다.
- 간격은 메인 CSS에 실제로 쓰인 값을 우선 재사용합니다. 정의되지 않은 별도의 spacing scale이 있는 것처럼 가정하지 않습니다.
- 콘텐츠 양이 다르다는 이유로 메인 페이지의 섹션 순서나 디자인을 바꾸지 말고, 서브 페이지의 콘텐츠 구조 안에서 동일한 간격 원칙을 적용합니다.

## 7. Components

### Header / GNB
- `.header`: 화면 상단에 배치되는 absolute 헤더, 높이 76px, z-index 20.
- `.logo a`: 블루 로고 텍스트, 20px, 800.
- `.gnb`: 가로 정렬 메뉴. 메뉴 간격은 반응형 `clamp()` 사용.
- `.header_util`: 언어 버튼과 메뉴 버튼을 오른쪽에 정렬.
- `.menu_btn`: 두 개의 가는 선으로 구성된 메뉴 버튼.
- `.mega-menu`: GNB 아래에 열리는 전체 폭 메뉴. 제목·하위 링크·이미지의 3열 구조.
- GNB와 메가 메뉴 링크는 브랜드 공식 사이트로 연결하지 않습니다. 현재 프로젝트 내부 경로 또는 페이지 내 앵커를 사용하고, 실제 서브 페이지 연결 시 해당 프로젝트 파일 경로로 지정합니다.

### 버튼 및 탭
- R&D 좌우 이동 버튼: 34×34px 원형, 이전/다음 버튼을 배경색과 아이콘 색상으로 구분.
- R&D 탭: 둥근 pill 형태(`border-radius: 28px`), 기본은 반투명 흰색, 활성은 `--blue-tab-active`.
- 언어 버튼과 메뉴 버튼: 투명 배경, 흰색 텍스트/선.
- 버튼에 새로운 그림자나 과도한 둥근 모서리를 임의로 추가하지 않습니다.

### 카드
- R&D 카드: 내부 padding 12px, border-radius 13px, 반투명 네이비 배경, 이미지 영역 높이 200px.
- 회사소개 카드: 4개 이미지 배경 카드. 텍스트는 중앙 정렬이며 이미지 위 오버레이보다 앞에 배치.
- ESG 항목: 가로형 컬러 패널, radius 30px, 이미지 radius 18px.
- 소식 유리 카드: padding 28px 24px, radius 20px, 반투명 흰색 배경, blur 16px, 얇은 흰색 테두리와 그림자.
- 소식 솔리드 카드: padding 24px, radius 18px, 짙은 네이비 배경. `.feature-blue`는 블루 배경으로 강조.
- 서브 페이지에서 같은 성격의 콘텐츠를 카드로 표현할 때 해당 카드 유형 중 가장 가까운 것을 선택합니다.

### 링크 및 목록
- ESG '자세히 보기': 텍스트와 화살표를 가로 정렬하고, 반투명 배경과 작은 radius를 사용.
- IR 목록: 가로 Flex로 텍스트와 우측 화살표를 양 끝에 배치하며, 블루 계열 구분선을 사용.
- 푸터 SNS: 원형 테두리 링크(25×25px).
- 링크는 일반 텍스트와 구분될 수 있도록 기존 영역의 색상·화살표·밑줄 규칙을 따릅니다. 현재 메인 CSS에는 모든 링크에 공통 밑줄이 적용되어 있지 않으므로, 임의로 전체 링크에 밑줄을 추가하지 않습니다.

### Footer
- `.footer`: 흰색 배경, 상단 1px 회색 선.
- `.footer-inner`: 로고·회사 정보·SNS를 Flex로 배치.
- 로고는 블루, 정보는 회색, SNS는 원형 테두리로 표현.
- 서브 페이지에서도 공통 푸터 구조와 정보 위계를 유지합니다.

## 8. Interaction

### 현재 코드에서 확인되는 상태 표현

| 대상 | 상태 | 시각적 변화 |
|---|---|---|
| GNB 링크 | Hover | 투명도 0.65 |
| GNB 링크 | 활성 메뉴 | 아래쪽 2px 블루 선이 왼쪽에서 펼쳐짐 |
| Header | 메가 메뉴 열림 | 어두운 반투명 배경과 그림자 적용 |
| 메가 메뉴 | 열림/닫힘 | opacity, visibility, translateY로 표시 전환 |
| 메가 메뉴 하위 링크 | Hover / Focus-visible | 글자색 `#69b5ff` |
| 회사소개 카드 | Hover | 배경 이미지가 1.06배 확대 |
| R&D 탭 | Active 클래스 | 블루 배경과 흰색 글자 |
| HERO 슬라이드 | 활성 페이지 | 페이지네이션 bullet이 흰색으로 변경 |

### Transition
- GNB 투명도: `0.2s`
- GNB 활성 밑줄: `transform .2s ease`
- Header 배경·그림자: `0.25s ease`
- 메가 메뉴: `opacity .25s ease`, `transform .25s ease`, `visibility .25s`
- 회사소개 이미지 확대: `transform .5s`
- 메가 메뉴 링크 색상: `color .2s ease`

### Focus / 접근성
- 공통 `css/default.css`에서 `:focus`의 기본 outline을 초기화하고, `:focus-visible`에 `2px` 실선 outline과 `2px` offset을 적용합니다.
- 메가 메뉴 링크는 별도로 `:focus-visible`일 때 파란색으로 변경됩니다.
- 메뉴 버튼은 `aria-expanded` 값으로 열림 상태를 전달하고, 메가 메뉴는 `aria-hidden` 값으로 표시 상태를 전달합니다.
- `prefers-reduced-motion: reduce` 환경에서는 애니메이션·전환 시간을 거의 제거하고 부드러운 스크롤을 해제합니다.

### 구현 시 주의
- 키보드 사용자가 현재 위치를 확인할 수 있도록 Focus 표시를 제거하지 않습니다.
- Hover만으로 중요한 정보를 제공하지 않습니다. 터치 화면에서는 Hover가 동일하게 동작하지 않을 수 있으므로 클릭·키보드 동작도 고려합니다.
- 현재 메인 CSS에는 모든 버튼·카드에 공통으로 정의된 Hover, Active 스타일이 있는 것은 아닙니다. 정의되지 않은 상태를 기존 디자인 규칙인 것처럼 문서화하거나 복제하지 않습니다.
- R&D 탭의 활성 클래스는 HTML에 기본으로 지정되어 있지만, 제공된 스크립트에는 탭 전환 동작이 구현되어 있지 않습니다. 서브 페이지에서 탭 기능을 추가할 경우 상태 변경 동작과 접근성 속성을 함께 구현합니다.

## 9. Responsive Rules

### 코드에서 확인되는 브레이크포인트

#### 900px 이하
- 회사소개: 4열에서 2열로 변경, 섹션 및 카드 최소 높이 693px.
- 소식: 좌측 소개와 콘텐츠의 2열 구조를 1열로 변경.
- 소식 카드: 2열에서 1열로 변경.
- 메가 메뉴: CSS에 2열 규칙과 3열 규칙이 서로 다른 위치에 선언되어 있습니다. 뒤쪽에 선언된 동일 우선순위 규칙이 앞선 규칙을 덮어쓸 수 있으므로 실제 적용 결과를 확인해야 합니다.

#### 600px 이하
- 메가 메뉴 내부 열을 2열로 변경하는 규칙이 있습니다.
- 앞쪽 미디어 쿼리에는 이미지 숨김 규칙도 있으나, 뒤쪽에 같은 선택자의 그리드 규칙이 다시 선언됩니다. 이미지 표시 여부와 최종 열 구조는 실제 브라우저에서 확인해야 합니다.

#### 유동형 크기
- HERO 높이: `min(760px, 66vw)`, 최소 500px.
- HERO 문구, R&D 제목, 회사소개 제목, ESG 제목은 `clamp()`로 화면 너비에 따라 크기가 달라집니다.
- GNB 간격도 `clamp(22px, 4vw, 64px)`로 조절됩니다.

### 서브 페이지 제작 기준
- 공통 컨테이너는 `.section-inner`를 우선 사용합니다.
- 기존 900px·600px 기준을 먼저 참고하되, 새 페이지의 콘텐츠가 실제로 깨지는 지점이 있는지 확인한 뒤 필요한 규칙만 추가합니다.
- 모바일에서 가로 스크롤이 발생하지 않는지, 제목·버튼·카드가 겹치지 않는지, 이미지가 잘리지 않는지 확인합니다.
- 현재 메인 CSS에는 R&D·ESG·Footer·GNB 전체에 대한 완전한 모바일 대응 규칙이 확인되지 않습니다. 따라서 이 영역의 모바일 동작을 이미 확정된 디자인 규칙으로 간주하지 말고, 서브 페이지 제작 시 화면 테스트를 통해 보완합니다.

## 10. Do & Don't

### DO
- 메인 페이지의 블루·네이비 중심 컬러와 Pretendard Variable을 사용합니다.
- `.section-inner`의 최대 너비와 좌우 여백을 공통 기준으로 삼습니다.
- 기존 Header, GNB, 메가 메뉴, Footer의 구조와 시각적 위계를 재사용합니다.
- 콘텐츠 종류에 따라 R&D 카드, 회사소개 이미지 카드, ESG 가로 패널, 소식 카드, IR 목록 중 적절한 컴포넌트를 참고합니다.
- CSS 변수를 우선 사용하고, 이미 존재하는 값은 변수명까지 함께 유지합니다.
- Hover·Focus-visible·Active 상태를 함께 검토합니다.
- 모바일과 키보드 탐색 환경에서 실제 동작을 확인합니다.
- 새 서브 페이지 링크는 현재 리뉴얼 프로젝트 내부의 실제 페이지 경로로 연결합니다.

### DON'T
- 메인 페이지의 기존 디자인이나 콘텐츠 순서를 임의로 변경하지 않습니다.
- 기존 코드에 없는 색상·폰트·간격·그림자·radius 수치를 근거 없이 브랜드 규칙으로 추가하지 않습니다.
- 한국콜마 공식 브랜드 사이트로 연결되는 링크를 사용하지 않습니다.
- 모든 섹션을 똑같은 카드 디자인으로 통일하지 않습니다. 콘텐츠 목적에 맞는 기존 컴포넌트를 선택합니다.
- Hover만으로 메뉴나 핵심 정보를 제공하지 않습니다.
- `:focus-visible` 표시를 제거하거나 키보드 조작을 막지 않습니다.
- CSS 변수의 이름과 역할을 확인하지 않고 임의로 재활용하지 않습니다.
- 메인 CSS에 존재하지 않는 모바일 레이아웃을 이미 구현된 것처럼 가정하지 않습니다.
